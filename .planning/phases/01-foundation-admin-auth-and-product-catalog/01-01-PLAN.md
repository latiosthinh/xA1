# Plan 01-01: Foundation, Turso DB, Admin Auth & Product Catalog

## Objective
Initialize the Next.js 15 App Router application with Tailwind CSS and Lucide icons, configure the Turso LibSQL database connection and Drizzle schema for products, implement simple `.env`-based admin authentication using `jose` cookies and Next.js middleware, and build a full product CRUD admin dashboard.

## Implementation Steps

1. **Scaffold Next.js 15 App & Dependencies**:
   - Install Next.js 15, React 19, Tailwind CSS, `@libsql/client`, `drizzle-orm`, `drizzle-kit`, `jose`, `lucide-react`, `clsx`, `tailwind-merge`.
   - Setup `tsconfig.json`, `tailwind.config.ts`, and base layout with root stylesheet.

2. **Database Layer (Turso LibSQL + Schema)**:
   - Create `src/lib/db.ts` with `@libsql/client` and automatic table initialization for `products`, `orders`, and `order_messages`.
   - Setup `src/lib/schema.ts` defining columns: `id`, `name`, `description`, `price`, `image_url`, `created_at`.

3. **Authentication Layer (`jose` + `.env`)**:
   - Setup `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_JWT_SECRET` in `.env.example`.
   - Create `src/lib/auth.ts` with functions to sign and verify admin JWTs in HTTP-only cookies.
   - Implement `src/middleware.ts` protecting `/admin` (except `/admin/login`) and `/api/admin/*` endpoints.
   - Implement API routes `src/app/api/auth/login/route.ts` and `src/app/api/auth/logout/route.ts`.

4. **Admin UI & Product CRUD**:
   - Create `/admin/login` page with username/password form and error states.
   - Create `/admin` dashboard with product table, Add Product modal/drawer, Edit Product modal, and Delete confirmation.
   - Create API routes `src/app/api/admin/products/route.ts` (GET all, POST create) and `src/app/api/admin/products/[id]/route.ts` (PUT update, DELETE delete).

5. **Self-Verification & Test Suite**:
   - Create unit/integration verification script checking database connectivity, product CRUD, and auth token issuance.
   - Verify `npm run build` passes cleanly with zero TypeScript/lint errors.
