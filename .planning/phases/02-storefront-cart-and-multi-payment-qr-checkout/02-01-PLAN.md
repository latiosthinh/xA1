# Plan 02-01: Storefront, Cart & Multi-Payment QR Checkout

## Objective
Implement the public storefront displaying products fetched from Turso LibSQL, a responsive slide-over cart drawer with quantity adjustments and live pricing, an order creation API returning short `publicMemo` and secure `clientToken`, and an interactive Checkout Modal featuring MoMo QR code, Binance Pay ID, 1-click clipboard copy, and a "Done" submission trigger that transitions order state to `PAID_WAITING_CONFIRM` with 5-10 minute wait guidance.

## Implementation Steps

1. **Public Product API (`src/app/api/products/route.ts`)**:
   - Return all published products from Turso SQLite without authentication.

2. **Order APIs**:
   - `src/app/api/orders/route.ts`: POST to create an order, generate short `publicMemo` (e.g. `ORD-1234`), generate `clientToken`, save items and totals to DB.
   - `src/app/api/orders/[id]/pay/route.ts`: POST to mark order as `PAID_WAITING_CONFIRM`.

3. **Storefront & Cart UI Components**:
   - `src/components/Navbar.tsx`: Store brand header, Cart trigger with live item count badge, and placeholder for Phase 3 notification bell.
   - `src/components/ProductCard.tsx`: Product item display, image fallback, quantity selector increment/decrement, and "Add to Cart" button.
   - `src/components/CartDrawer.tsx`: Slide-over drawer with item list, quantity modifier, remove item, subtotal, and "Proceed to Payment" button.

4. **Multi-Payment Modal (`src/components/PaymentModal.tsx`)**:
   - Tabs for MoMo QR and Binance Pay ID.
   - Dynamic SVG QR code rendered via `qrcode.react` (`QRCodeSVG`).
   - 1-click Copy buttons for:
     - Binance Pay ID
     - MoMo Phone & Account Name
     - Exact Amount
     - Order ID Memo (`publicMemo`)
   - Explicit instructions highlighting the required transfer description.
   - "Done / I Have Paid" button which calls `/api/orders/[id]/pay`, records order in user's `localStorage` (`mmo_customer_orders`), and displays a success alert with the 5-10 minute processing note.

5. **Home Page (`src/app/page.tsx`)**:
   - Integrate `Navbar`, product grid, `CartDrawer`, and `PaymentModal`.

6. **Self-Verification**:
   - Create `verify-phase2.mjs` verifying public order creation and payment confirmation state transitions.
   - Run `npm run build` to verify clean compilation.
