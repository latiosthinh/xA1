# Plan 03-01: Telegram 2-Way Bot Bridge & Realtime Ephemeral Notification

## Objective
Implement Telegram bot alert dispatch when customer confirms payment, build a secure Telegram webhook endpoint to parse admin `/reply <OrderID> <message>` commands, create client polling and acknowledgment endpoints for stored orders, and build the header Notification Bell with an ephemeral message modal and data loss warnings.

## Implementation Steps

1. **Telegram Service (`src/lib/telegram.ts`)**:
   - Helper function `sendTelegramOrderAlert(order)` to send formatted Markdown messages with item list, total, and reply syntax to `TELEGRAM_ADMIN_CHAT_ID`.
   - Bot instance helper using `grammy`.

2. **Integrate Telegram Alert in Pay API (`src/app/api/orders/[id]/pay/route.ts`)**:
   - Upon updating status to `PAID_WAITING_CONFIRM`, trigger `sendTelegramOrderAlert` asynchronously with error catching.

3. **Telegram Webhook Endpoint (`src/app/api/telegram/webhook/route.ts`)**:
   - Handle incoming updates from Telegram.
   - Verify `X-Telegram-Bot-Api-Secret-Token` (if set).
   - Parse `/reply <publicMemo> <content...>` or `/reply <id> <content...>`.
   - Insert message record into `order_messages` in Turso LibSQL mapped to the matching order.
   - Reply to admin in Telegram confirming delivery: `Message for ORD-XXXX queued for customer.`

4. **Client Polling & Acknowledge APIs**:
   - `src/app/api/orders/poll/route.ts`: Accepts list of `{ orderId, clientToken }`, looks up non-acknowledged messages in `order_messages`, marks them `DELIVERED`, and returns them.
   - `src/app/api/orders/acknowledge/route.ts`: Accepts `messageId` and `clientToken`, updates message status to `ACKNOWLEDGED`.

5. **Notification Bell & Ephemeral Delivery UI**:
   - `src/components/NotificationBell.tsx`: Polls `/api/orders/poll` every 4 seconds for all orders in `localStorage`. Rings with pulsating badge when unread messages are found.
   - `src/components/EphemeralMessageModal.tsx`: Displays the message content with explicit warning banner: *"Warning: This content will disappear after closing this modal. Please copy and store your data now!"*, 1-click Copy button, and an "I have saved my data - Close" button that invokes the acknowledge API.
   - Wire `NotificationBell` into `src/components/Navbar.tsx` and `src/app/page.tsx`.

6. **Self-Verification**:
   - Create `verify-phase3.mjs` verifying message creation, polling with client tokens, and acknowledgment state flow.
   - Run `npm run build` to verify full compilation.
